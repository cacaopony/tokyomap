# 東京凸凹散歩（Tokyo Relief Walk）

東京23区を歩くときに、その土地の **高低差（台地・谷・低地）** と **歴史** を一緒に楽しめる地図 Web アプリ。

## 起動

```bash
npm install
npm run dev      # http://localhost:5173 （同じWi-Fiのスマホからは表示される Network URL で）
npm run build    # dist/ に静的ファイルを出力
```

## 主な機能

| 機能 | 内容 |
| --- | --- |
| 色別標高（段彩） | 国土地理院の5mメッシュ標高を独自の配色で塗り分け。23区向けに 0〜40m に色を集中（10〜100mで調整可）。配色は「鮮やか / 地形図風 / ナイト」、1m・2m・5m刻みの段彩も |
| 陰影・3D | 陰影起伏と3D地形表示（高さの強調 ×1〜8） |
| 歴史スポット | 23区すべてに計132件（＋23区外3件、既定で非表示）。時代・区・キーワードで検索、近い順・区ごと・時代順に一覧 |
| 地点の標高 | 地図をタップすると、その地点の標高と地形の目安、近くのスポットを表示 |
| 断面図 | 2点を指定すると高低差・上り下り・最大勾配を表示。グラフをなぞると地図上の位置に連動 |
| 海面シミュレーション | 海面を上げて低地と台地の境目を可視化（縄文海進 +3m のプリセット付き） |
| 昔の東京を重ねる | 1936〜42年 / 1945〜50年 / 1961〜69年 / 1974〜78年の空中写真、明治期の低湿地、土地条件図 |
| 現在地 | 現在地の標高と最寄りのスポットを表示 |

## 構成

```
index.html
src/
  main.js          地図・UI 全体
  dem.js           標高タイルの読込と変換（gsidem:// = 3D/陰影用, relief:// = 色別標高）
  palette.js       標高→色のルックアップテーブル、海面シミュレーション
  profile.js       断面図（SVG）
  style.css
  data/spots.js    歴史スポット（区・時代・種類・本文・地形メモ）
  data/terrain.js  台地・低地・川の名前ラベル
vite.config.js     MapLibre の Web Worker を public/vendor にコピー
```

スポットを追加するときは `src/data/spots.js` に1件ずつ追記してください（`ward` は `WARDS` の区名、23区外は `'23区外'`）。

## データ・出典

- 地図・標高・空中写真：[国土地理院（地理院タイル）](https://maps.gsi.go.jp/development/ichiran.html)
- 地図ライブラリ：[MapLibre GL JS](https://maplibre.org/)
- スポットの位置はおおよその地点で、内容には通説・伝承を含みます。

## iPhone アプリ化に向けて

1. **PWA**（すでに manifest 対応済み）：HTTPS で公開すれば Safari の「ホーム画面に追加」でアプリのように使える。現在地は HTTPS が必須なので、GitHub Pages / Cloudflare Pages などで公開するのが最初の一歩。
2. **Capacitor** でネイティブアプリ化：`npm i @capacitor/core @capacitor/ios` → `npx cap add ios` で、この Web アプリをそのまま iOS アプリに包める（ビルドには Mac + Xcode が必要）。
3. 将来的に：オフライン用のタイルキャッシュ、散歩コース、写真付きスポット、スポットの音声ガイドなど。
